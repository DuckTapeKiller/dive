              Dive only ever rewrites the block it marks as its own. Comments,
              `[*]` globals and hand-written sections outside that block are
              left alone — including sections whose name it would otherwise
              generate, so an embedding model keeps the alias your vector index
              is keyed to. The first write leaves a `.dive-backup` copy beside
              the file. Sections Dive did not write are reported as stale when
              their model disappears, never deleted for you.
